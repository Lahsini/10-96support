# 10-96 Support Center — GitHub Pages

A static, responsive, accessibility-conscious support and policy website.

## Files

- `index.html` — existing support landing page, FAQ and contacts, enhanced with policy links
- `privacy.html` — comprehensive Privacy Policy
- `content-rights.html` — Content Rights & Disclaimers
- `styles.css` — shared styling (no JavaScript dependencies)
- `.nojekyll` — GitHub Pages passthrough

## Deploy to GitHub Pages

1. Open the GitHub repository serving `https://lahsini.github.io/10-96support/`.
2. Upload/replace these files at the repository root on the branch used by GitHub Pages. Keep `.nojekyll`.
3. Do not delete other repository files unless you know they are obsolete.
4. Confirm the site displays at `https://lahsini.github.io/10-96support/`.
5. Confirm both policy pages work at the paths below.
6. Update the Privacy Policy URL in App Store Connect, and add a Privacy Policy link in the in-app Privacy & App Information page if not already present.

### URL to use in App Store Connect

**Privacy Policy URL:** `https://lahsini.github.io/10-96support/privacy.html`

**Support URL:** `https://lahsini.github.io/10-96support/`

**Content Rights:** `https://lahsini.github.io/10-96support/content-rights.html`

The Privacy URL becomes live **only after the site is deployed**. This archive does not publish itself to GitHub.
